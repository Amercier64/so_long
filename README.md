# Description

The 42 project So_long. This is a graphical project, a 2D maze of the user's choosing is displayed on a window through the use of the minilibX. User has to find the exit after collecting collectibles.
The point of the project is to familiarize yourself with a different library with its own documentation. There is also a strict parsing to implement. The graphical and logical aspect of the project are straightforward and relatively easy to implement.
# Instructions

Download the mlx from the subject page, extract it and put it under the libs directory. Run "$ make". Run the program with a map of your choosing.
Using the following characters and map constraints:
### Allowed Characters:

| Charater | Description |
| :--- | :--- |
| **0** | Empty space |
| **1** | Wall |
| **P** | Player starting position |
| **C** | Collectibles |
| **E** | Exit |

### Map Constraints

* **Required Elements**: The map must contain exactly **1 exit**, exactly **1 starting position**, and at least **1 collectible**.
* **Shape**: The map must be **rectangular**.
* **Walls**: The map must be completely **enclosed and surrounded by walls**.
* **Validity**: There must be a **valid path** that allows the player to reach all collectibles and the exit from their starting position.
